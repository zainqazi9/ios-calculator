# iOS Calculator 📱

A browser-based calculator faithfully reproducing the native Apple iOS calculator design system and arithmetic engine.

## 📌 Features
- **iOS Dark Theme Design:** Charcoal display, dark grey numeric keys (`#333`), vibrant orange operators (`#FF9500`), and light grey utility keys (`#A6A6A6`).
- **Pill-shaped 0 Key:** Extended rounded button matching iOS proportions.
- **Arithmetic Engine:** Addition, subtraction, multiplication (`×`), division (`÷`), and percentage (`%`).
- **Backspace & Clear:** Single-digit backspace deletion (`⌫`) and instant clear (`C`).
- **Defensive Error Handling:** Integrated `try-catch` exception handling for syntax safety with automated error reset timeout.

## 💻 Tech Stack
- **HTML5:** Calculator structural layout.
- **CSS3:** Apple design system styling, circular flexbox buttons, and active press feedback.
- **JavaScript (ES6):** DOM manipulation, expression evaluation, and event listeners.
